# QA Automation — Playwright

Навчально-портфоліо проєкт з автоматизованого тестування.
Автотести написані на **Playwright** (JavaScript) з використанням патерну **Page Object Model** та автоматичним запуском через **CI/CD** (GitHub Actions).

## 🛠 Технології

- **Playwright** — фреймворк для E2E-тестування
- **JavaScript** — мова програмування
- **Page Object Model (POM)** — архітектурний патерн
- **GitHub Actions** — CI/CD, автоматичний запуск тестів
- **Node.js** — середовище виконання

## 📁 Структура проєкту

- `tests/` — автотести (.spec.js)
- `pages/` — Page Objects (опис сторінок)
- `.github/workflows/` — конфігурація CI/CD
- `learning/` — навчальні вправи з основ JavaScript

## ✅ Що протестовано

- Авторизація: позитивний та негативний сценарії логіну
- Робота з елементами форм: чекбокси, випадні списки
- Взаємодія зі сторінкою: кліки, переходи, перевірка тексту
- Кросбраузерне тестування (Chromium, Firefox, WebKit)

## 🚀 Як запустити

Встановити залежності:

````````````
npm install
````````````

Встановити браузери:

````````````
npx playwright install
````````````

Запустити всі тести:

````````````
npx playwright test
````````````

Запустити з відкритим браузером:

````````````
npx playwright test --headed
````````````

Переглянути звіт:

````````````
npx playwright show-report
````````````
